# What is it?
It's in the name! **Minecraft OP Manager** is a simple application made with Python that, well, manages operators on your Minecraft server!

For **those who don't know**, there are levels of operator permissions in Minecraft:

**Level 1** (moderator)
    Player can bypass spawn protection.

    
**Level 2** (gamemaster)
    Player or executor can use more commands and player can use command blocks.

    
**Level 3** (admin)
    Player or executor can use commands related to multiplayer management.

    
**Level 4** (owner)
    Player or executor can use all of the commands, including commands related to server management.
    

(definitely not stolen from the [minecraft wiki](https://minecraft.fandom.com/wiki/Permission_level) lmao)
